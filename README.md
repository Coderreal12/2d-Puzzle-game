2D PUZZLE GAME

I am excited to show you my latest game my 2d puzzle game! 

While it looks easy on the surface its hard!

Controlls:

W =  Jump
A/D  = Right/Left
Shift = Run

E = Pickup crate's
R = Let Go of crates

W (While Looking at a wall) = Wall jump (Can wall jump twice before hitting the ground.
